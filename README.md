# 🐱 vs-cat

Легковесный CLI-подсветчик синтаксиса через ANSI escape-коды. Если нужно **быстро взглянуть на код без запуска полноценного редактора** в SSH-сессии или просто из терминала - тебе сюда.

---

## ✨ Особенности

- **Нулевые зависимости** — только стандартная библиотека Python 3.
- **Конфигурируемая подсветка** через JSON: легко добавить свой язык или кастомные правила.
- **Поддержка чисел** — `"0-9"` автоматически раскрывается во все цифры.
- **Режим строк** (`strings_view`) — строковые литералы выделяются отдельно.
- **Нумерация строк** — опционально, настраивается в конфиге.
- **16 цветов + стили** (bold, italic, underline, strike и др.) + комбинации с bold (`red-bold`, `cyan-bold`).
- **Пайплайн-совместимость** — работает в цепочках `cat | vs-cat | less -R`.

## 🚀 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/arthuraswork/vs-cat
cd vs-cat

# Установить (копирует в ~/.local/bin/vs-cat и создаёт symlink)
./vscat install
```

После установки:
- Основной скрипт: `~/.local/bin/vs-cat/vscat.py`
- Конфиг: `~/.local/bin/vs-cat/vscat.json`
- Команда: `vscat <файл>`

## 💻 Использование

### Базовый вызов
```bash
vscat script.py
vscat main.go
vscat config.json
```

### В пайплайнах
```bash
# Посмотреть Python-скрипт с пейджером
vscat script.py | less -R

# Подсветить вывод grep
grep -n "def " script.py | vscat script.py | less -R

# Следить за логом в реальном времени
tail -f server.log | vscat server.log
```

### Без установки (напрямую)
```bash
python3 vscat.py script.py vscat.json
```

## ⚙️ Конфигурация

Конфиг хранится в `vscat.json`. Формат:

```json
{
  "py": {
    "red": ["if", "else", "def", "class", "return", "elif", "for", "in", "import"],
    "blue": ["0-9"],
    "bold": [":", ","],
    "yellow": ["[", "]", "(", ")", "{", "}"],
    "numeration": true,
    "strings_view": true
  }
}
```

### Структура конфига

| Ключ | Тип | Описание |
|------|-----|----------|
| `<цвет>` | `list[str]` | Список слов/символов для подсветки этим цветом |
| `numeration` | `bool` | Добавить номера строк |
| `strings_view` | `bool` | Выделять строковые литералы зелёным |

### Доступные цвета и стили

| Цвет | Суффикс для жирного |
|------|---------------------|
| `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`, `black` | `red-bold`, `green-bold`, ... |
| Дополнительные стили | `bold`, `italic`, `underline`, `strike`, `dim`, `reverse` |

## 📦 Поддерживаемые языки "из коробки"

- 🐍 **Python** — ключевые слова, числа, скобки, строки
- 🦀 **Go** — ключевые слова, операторы, типы, строки
- ⚙️ **C** — полная подсветка с препроцессором (`#include`) и побитовыми операторами
- 📋 **JSON** — структуры, булевые значения, числа

### Как добавить свой язык

Просто добавь новый блок в `vscat.json`:

```json
{
  "rs": {
    "red": ["fn", "let", "mut", "struct", "impl", "pub", "use"],
    "cyan": ["String", "i32", "bool"],
    "numeration": true,
    "strings_view": true
  }
}
``` 

Расширение файла определяется автоматически по суффиксу (`file.rs` -> блок `"rs"`).
